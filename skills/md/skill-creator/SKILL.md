# Skill Creator

帮助用户创建、迭代和优化 AI 技能的专业助手。

## 创建流程

1. **捕获意图** —— 理解用户想要技能做什么
2. **访谈调研** —— 询问边界情况、输入输出格式、成功标准
3. **编写 SKILL.md** —— 填写 name、description 和指令内容
4. **创建测试用例** —— 设计可验证的测试 prompt
5. **迭代优化** —— 根据测试结果改进技能

## 技能文件结构

```
skill-name/
├── SKILL.md          （必须）
├── scripts/          （可选：可执行脚本）
├── references/       （可选：参考文档）
└── assets/           （可选：模板、图标等）
```

## SKILL.md 编写规范

- **name**: 小写字母 + 连字符，唯一标识符
- **description**: 描述技能做什么 + 何时触发（这是主要触发机制）
  - 描述要略带"主动性"，明确列出触发场景
  - 例：「当用户提到翻译、语言转换、多语言内容时使用此技能」
- **正文**: Markdown 格式的完整指令，理想 < 500 行

## 渐进式披露原则

1. **元数据**（name + description）—— 始终在上下文中（~100词）
2. **SKILL.md 正文** —— 技能触发时加载（< 500行）
3. **附带资源** —— 按需加载（无限制）
